
# ЗВІТ
## Лабораторна робота № 1

### Тема
Розробка першої версії консольного продукту.

### Мета роботи
Створити консольну програму для зчитування, перевірки та обробки набору записів відповідно до заданої предметної області.

### 1. Аналіз та проєктування програми

Предметною областю програми є каталог книжок. Кожна книжка описується чотирма полями:

- title — назва книжки;
- author — автор;
- pages — кількість сторінок;
- price — ціна.

Інформація зберігається у CSV-файлі, де поля розділяються крапкою з комою.

Програма повинна зчитувати записи, перевіряти їхню коректність, обчислювати показники та формувати звіт.

### 2. Загальний потік обробки

Main

↓

↓

↓

data/report.txt

### 3. Реалізація та конфігурація проєкту

Програма реалізована мовою Java.

Для реалізації використовуються:
- String[] — для зберігання полів запису;
- ArrayList — для зберігання коректних книжок;
- Path та Files — для роботи з файлами;
- BufferedReader — для читання вхідних даних;
- StringBuilder — для формування звіту;
- try-catch — для обробки помилок.

Для роботи з файлами використовується кодування UTF-8.

Програма підтримує аргументи командного рядка:
- --help;
- --input;
- --output.

### 4. Валідація вхідних даних

Під час читання кожного рядка виконуються такі перевірки:

- порожні рядки;
- кількість полів;
- title;
- author;
- pages;
- price.

Некоректні записи пропускаються. Програма повідомляє номер рядка та причину помилки.

Приклад повідомлення:

Рядок 2: неправильна кількість полів.
Рядок 3: назва книжки відсутня.
Рядок 4: неправильний формат числових даних.

### 5. Обчислення показників

Програма обчислює три показники:

1. Середня кількість сторінок.
2. Найдорожча книжка.
3. Сумарна вартість каталогу.

### 6. Формування звіту

Результати обчислень формуються у текстовий звіт.

Для форматування числових значень використовується String.format та Locale.ROOT.

Звіт виводиться в консоль і зберігається у файлі data/report.txt.

### 7. Тестування програми

Під час тестування перевірено:

- зчитування правильних записів;
- пропуск порожніх рядків;
- неправильну кількість полів;
- відсутність назви або автора;
- неправильний формат числових даних;
- нульову та від'ємну кількість сторінок;
- від'ємну ціну;
- формування звіту;
- збереження звіту у файл.

### 8. Висновок

Під час виконання лабораторної роботи було створено консольну програму мовою Java для роботи з каталогом книжок.

Реалізовано зчитування даних із CSV-файлу, перевірку коректності записів, обчислення основних показників та формування звіту.

Програма підтримує роботу з UTF-8, аргументи командного рядка та обробку помилкових записів без аварійного завершення роботи.
