# Каталог книжок

## Призначення програми

Консольна програма на Java для роботи з каталогом книжок.

Програма зчитує записи з CSV-файлу, перевіряє правильність даних, обчислює показники та формує звіт.

## Структура запису

Кожен запис містить чотири поля:

- title — назва книжки (String);
- author — автор (String);
- pages — кількість сторінок (int);
- price — ціна (double).

Поля розділяються крапкою з комою (;).

Приклад:

Кобзар;Тарас Шевченко;320;250.50

## Обчислювані показники

1. Середня кількість сторінок.
2. Найдорожча книжка.
3. Сумарна вартість каталогу.

## Перевірка даних

Програма перевіряє:
- порожні рядки;
- кількість полів;
- наявність назви та автора;
- правильність кількості сторінок;
- правильність ціни.

Некоректні записи пропускаються з повідомленням про помилку.

## Запуск програми

Для компіляції:

javac -encoding UTF-8 -d out src/Main.java

Звичайний запуск:

java -cp out Main

Довідка:

java -cp out Main --help

Власний вхідний файл:

java -cp out Main --input data/input.csv

Власний вихідний файл:

java -cp out Main --output data/report.txt

Вказання обох файлів:

java -cp out Main --input data/input.csv --output data/report.txt

## Результат

Звіт виводиться у консоль та зберігається у файлі data/report.txt.
